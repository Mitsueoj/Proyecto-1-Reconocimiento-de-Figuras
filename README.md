# Instalacion y Ejecucion

## Requisitos e Instalacion de Pip

Si no tienes pip instalado, instala pip según tu sistema:

* Windows:
  python -m ensurepip --upgrade

* Linux (Ubuntu/Debian):
  sudo apt update && sudo apt install python3-pip python3-tk

* macOS:
  sudo python3 -m ensurepip --upgrade

---

## Instalacion de Librerias

Ejecuta el comando correspondiente al sistema operativo para instalar opencv-python, numpy, Pillow y tkinter:

* Windows:
  pip install opencv-python numpy Pillow

* Linux:
  pip3 install opencv-python numpy Pillow python3-tk

* macOS:
  brew install python-tk && pip3 install opencv-python numpy Pillow

---

## Como Ejecutar el Codigo

Abre la terminal en la carpeta src/ del proyecto y ejecuta:

* Windows:
  python main.py

* Linux / macOS:
  python3 main.py
